# LyricProto

Lời bài hát karaoke ngay trên màn hình Windows — đồng bộ với Spotify và YouTube, có phiên âm và dịch tiếng Việt tự động.

**Trang giới thiệu:** https://dinhvanhieu3011.github.io/lyricproto/
**Tải về:** [Release mới nhất](https://github.com/dinhvanhieu3011/lyricproto/releases/latest)

Windows 10/11 (64-bit). Không cần cài .NET.
